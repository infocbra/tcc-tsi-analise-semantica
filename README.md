Visão Geral do Projeto

Este repositório contém o código utilizado no Trabalho de Conclusão de Curso “Análise Semântica de Correspondência entre Perfis Profissionais do Catálogo Nacional de Cursos Técnicos (CNCT) e Ocupações no Mundo do Trabalho (CBO)”.

O objetivo é desenvolver uma metodologia baseada em Processamento de Linguagem Natural (PLN) para correlacionar, de forma automática, escalável e sem vieses, os perfis profissionais do CNCT com as ocupações previstas na CBO.

A análise utiliza duas abordagens:

  TF-IDF (linha de base)
  
  SBERT — modelo paraphrase-multilingual-mpnet-base-v2

Os resultados incluem métricas de desempenho, similaridades semânticas, ranking das ocupações mais próximas e validação via Precision@k (1, 3 e 5).
